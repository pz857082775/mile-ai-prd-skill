# UI 美观保障指南（`/ui` 阶段使用）

本文件确保 PRD 中的界面能被 AI 实现得"非常好看"。当需求涉及界面时，按本指南产出 UI 审美规范；并优先调用环境中可用的 UI/设计类 Skill。

## 1. 优先调用 UI 技能
- 若环境存在 UI 美化 / 设计稿生成 / 组件库 类 Skill，**主动调用**它来定视觉与组件，确保实现美观统一。
- 若无可调用 UI Skill，则按下方标准在 PRD 第 8 章写明规范，让编码 Agent 有据可依。

## 2. 参考优秀作品（审美锚点）
按项目类型参考标杆，提取可复用范式：
- **iOS APP**：Apple HIG、Apple 设计大奖作品、主流 App（微信/小红书/Notion）。
- **Android APP**：Material Design 3、Google 出品应用。
- **微信小程序/H5**：微信官方设计指南、Vant/微信 UI、主流小程序。
- **网页/管理后台**：Linear / Vercel / shadcn/ui / Ant Design Pro。
- **游戏**：Apple 设计、主流休闲/竞技游戏、Dribbble 动效趋势。
- 通用灵感：Dribbble、Behance、 Mobbin（移动端模式库）。

## 3. PRD 第 8 章必须写明（让 AI 实现美观）
- **视觉风格**：明确基调（如 极简 / 拟物 / 玻璃拟态 / 新拟态 / 品牌色驱动）。
- **色彩体系**：主色/辅色/中性色/语义色（成功/警告/错误），对比度达 WCAG AA。
- **字体与排版**：字号阶梯、行高、字重；中文字体栈。
- **间距栅格**：8pt 栅格、卡片圆角、阴影层级。
- **组件规范**：按钮/输入/列表/弹层/导航 的状态与样式。
- **动效**：转场、微交互、加载动画（克制、有意义）。
- **状态完备**：空态 / 加载态 / 错误态 / 成功态 各自的视觉。
- **响应式**：移动/平板/桌面断点与布局变化。
- **无障碍**：对比度、语义、键盘可达、字号可调。

## 4. 审美自检（交付前）
- [ ] 有统一设计语言，非拼凑
- [ ] 色彩/间距/圆角一致
- [ ] 状态齐全（空/加载/错/成功）
- [ ] 对比度达 WCAG AA
- [ ] 动效克制有意义
- [ ] 参考了至少 1 个优秀作品范式

## 5. 与编码衔接
- PRD 第 8 章即 UI 规范来源；交付时可提示编码 Agent："按 PRD 第 8 章视觉规范实现，优先复用组件库"。
- 若调用了 UI 技能生成设计稿，将设计稿链接/要点回填 PRD 第 8 章。
