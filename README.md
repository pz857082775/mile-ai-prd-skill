# 开发需求文档专家 (PRD Writer)

专为 AI 编写与优化专业开发需求文档（PRD / Spec）的 Skill。

- 中文自然语言交互
- 覆盖全平台：PC 网站 / H5 / 微信小程序 / 微信小游戏 / 网页小游戏 / iOS APP / Android APP
- 七阶段工作流 + 双/三评审 + 质量门禁
- 支持润色优化已有 PRD、基于现有界面/功能补全更完善需求
- 逻辑零错误、前瞻发散、实用/美观/逻辑/盈利 四维评估
- UI 美观保障（参考优秀作品 + 可调用 UI 技能）
- 输出兼容各种 AI 编程平台（Cursor / CodeBuddy / WorkBuddy / Claude / Cline / Windsurf 等）

## 安装
将本仓库的 `prd-writer/` 目录复制到你的 Skill 目录：
- WorkBuddy / CodeBuddy：`~/.workbuddy/skills/prd-writer/` 或 `~/.codebuddy/skills/prd-writer/`
- Claude Code：`~/.claude/skills/prd-writer/`

## 使用
对话中说「帮我写需求 / 出一份 PRD / 润色这份 PRD / 给我界面补充更完善需求」即可触发。详见 `prd-writer/SKILL.md`。
